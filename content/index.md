웹 서비스 개발로 시작해 지금은 사내 개발 인프라 전체를 맡고 있는 엔지니어입니다.
Spring Boot로 관리 콘솔과 관제 대시보드를 만들었고, 배포를 자동화하다가 인프라로 넘어왔습니다. 지금은 서버 10대 규모의 사내망에서 CI/CD, 사내 메신저, VPN, DB, 백업을 직접 세우고, 서버 한 대가 멈추면 업무가 같이 멈추던 구조를 장비 구매 없이 이중화했습니다.

일을 할 때는 실측부터 합니다. "될 것 같다" 대신 끊김 시간·손실 건수·온도를 재서 기록하고, 사고가 나면 원인과 재발 방지책을 문서로 남깁니다.

## 기술 스택

- **백엔드**: Java 17, Spring Boot, 전자정부 표준프레임워크(eGovFrame), Spring Security, Thymeleaf, MQTT, WebSocket
- **임베디드·빌드**: Python, Cython, Nuitka, PyInstaller, ARM64 크로스컴파일
- **OS·하드웨어**: Rocky Linux 9, Dell PowerEdge, iDRAC(IPMI), NanoPi(ARM64)
- **컨테이너·HA**: Docker, Docker Compose, Podman, keepalived(VRRP), Pacemaker, Patroni, etcd, systemd
- **DB·메시징**: PostgreSQL, MongoDB(replica set), MariaDB(GTID 복제), Redis, NATS
- **네트워크·보안**: nginx(L7·SNI stream), headscale(Tailscale), nftables, firewalld, Let's Encrypt(acme.sh)
- **CI/CD·협업**: Jenkins, JFrog Artifactory, GitLab, SonarQube, Rocket.Chat
- **기타**: Bash, Claude Code
