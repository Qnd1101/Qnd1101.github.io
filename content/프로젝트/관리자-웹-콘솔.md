## 배경

자사 솔루션의 관리자용 웹 콘솔입니다. 입사 후 처음 맡은 개발 프로젝트로, 사용자·권한 관리부터 게시판, 데이터 보존 정책까지 관리자 화면 전반을 만들었습니다.

## 구현

**사용자·권한**
- 사용자 관리 화면 레이아웃 재구성, 사용자 프로필(전화번호 형식 검증 포함)
- 권한 레벨 조정 기능
- 사용자 데이터 양식(엑셀) 다운로드

**다국어(i18n)**
- 화면뿐 아니라 컨트롤러가 돌려주는 메시지까지 다국어로 처리했습니다. 처음에는 컨트롤러가 한국어 문자열을 그대로 반환하고 있어서, 이를 전부 메시지 키로 바꾸고 언어별 파일로 분리했습니다.
- 콘솔 로그도 한국어 대신 영어로 통일했습니다.

**게시판·공지**
- 공지사항, 게시판, 퇴사자 게시판
- CKEditor 텍스트 에디터 통합

**데이터 보존 정책**
- 채팅 데이터 보존 기간을 관리자가 정하고, 기간이 지나면 자동 삭제할지 고르는 기능

**빌드·보안**
- 설정값 암호화, Jenkins 빌드 설정
- v0.0.1 ~ v0.0.3 릴리스

## 같이 한 일: 개발 환경 온보딩 문서

입사 초기(2025.01)에 사내 개발 환경을 세우면서 팀원용 가이드를 11편 썼습니다. Jenkins 설치·초기 세팅·프로젝트 세팅, Java·Gradle·PostgreSQL 설치, Eclipse(eGovFrame) 설정, GitLab 저장소 받기, 릴리스 노트와 태그 작성법입니다. 새로 온 사람이 문서만 보고 같은 환경을 만들 수 있게 하는 것이 목표였고, 이 습관이 이후 인프라 인수인계 문서 작업으로 이어졌습니다.

## 문제와 해결

| 문제 | 원인 | 해결 |
|---|---|---|
| 언어를 바꿔도 일부 메시지가 한국어로 나옴 | 컨트롤러가 한국어 문자열을 직접 반환 | 전부 메시지 키로 바꾸고 언어별 파일로 분리 |
| 데이터 보존 기간 설정이 저장되지 않음 | 화면만 먼저 만들고 DB 저장 로직이 없었음 | 저장과 기간 경과 시 자동 삭제까지 구현 |
| 게시판 번호가 어긋남, 계정 삭제 오류 문구 부정확 | 번호 계산 로직 오류, 예외 메시지 미정리 | 넘버링 수정, 오류 문구 정리 |
| 프로필 전화번호 형식이 제각각 | 입력값 검증 없음 | 형식 유효성 검사 추가 |

## 배운 점

다국어를 나중에 붙이면 화면·서버·로그를 모두 다시 훑어야 한다는 것을 직접 겪었습니다. 지금은 새 기능을 만들 때 처음부터 메시지 키로 작성합니다.
